# 计算物理模拟的性能优化方向

随着 vibe coding 工具越来越强，许多性能优化的实现工作已经可以交给 AI。在我的使用习惯里，比起亲手修改每一处代码，更常做的是告诉 AI 值得检查的方向，再根据实际测试判断效果。

这篇笔记整理了以 C++ 为主的粒子模拟和场模拟中，可以交给 AI 排查的一组性能优化方向。粒子模拟可以采用 CPU 与 GPU 协同，也可以把主要计算放在 GPU 上；场模拟则可以围绕 GPU 组织主要计算。具体选择取决于体系、算法和计算规模。

这份清单只是参考，并不完整，也不要求每个体系逐项采用。不同模型会有各自的优化策略。也许以后，连这些方向都不必再提示，AI 就能自行发现；到那时，这篇笔记大概也就过时了。
